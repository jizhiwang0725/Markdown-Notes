# 如何解决问题
1. **分析问题**  
   有些问题描述冗长复杂，需要从题目描述中知道
   - 能给什么输入
   - 需要怎么处理数据
   - 如何输出数据
  
2. **建立模型，设计算法**  
   设计一个算法。算法是指一套确定的、有限的、能解决特定问题的流程

3. **编写程序**  
   使用C++来实现算法

4. **调试、编译运行与测试**  
   如果是理解错了提议或者算法本身是不合适的，就要回到前面几个步骤重新设计

# 简单数学计算
## 浮点数
若是希望结果是有小数，应在整数后加 **.0**。

使用cout输出浮点数，默认保留不超过**6位有效数字**。如果数字过大或者过小，那么就会使用**科学计数法**输出。  

``` c
int main() {
    cout << 500.0/3 << endl; // 166.667
    cout << 0.000005/3 << endl; // 1.66667e-06
    cout <<5e6 / 3 + 5e-6 / 3 - 5e6 / 3 << endl; // 1.6666e-06
    return 0;  
}
```

在计算过程中，如果有效数字的位数超过了一定的限度，那么有效数字的**最右端**将会被省去。

## 牛吃草问题
评测任务是单位时间内**均匀增加的**。8台评测机30min可以刚好把评测对极了中的程序评测完毕，10台评测机6min可以刚好把评测队列中的程序评测完毕。问：几台评测机10min时刚好把评测队列中的程序评测完毕？

首先要分析每分钟有多少新的程序进入评测队列。  
8台评测机30min可以评测240份。  
10台评测机6min可以评测60份。  
可以得到在$30-6=24$min内，增长了$240-60=180$份。  
因此每分钟程序增长速度是$180/24=7.5$份/min。  

然后找到起始份数。6min可以测评60份，其中$6 \times 7.5 = 40$ 份是新提交的材料。得出原先队列里有15份程序。评测机10min一共需要评测$15+10  \times  7.5=90$份程序，所以需要$90/10=9$台。

``` c
int main() {
    int n1 = 8, t1 = 30, n2 = 10, t2 = 6; // 题目给出来的数量
    int t3 = 10 ; // 题目要求的时间
    double inc_rate = (1.0 * n1 * t1 - n2 * t2) / (t1 - t2); // 增长速度
    double init_num = n2 * t2 - inc_rate * t2; // 起始数量
    double ans = (init_num + t3 * inc_rate) / t3; // 答案
    return 0;
}
```

**自动类型转化**  
当一个整数类型除以一个浮点数整数，得出来的是浮点数。  
当浮点数转化为整数时，小数点后的位数会被省略掉。

**强制类型转化**  
```c
#define PI 3.141593

int main() {
    int r1 = 4, r2 = 10;
    double V, l;
    V = 4.0 / 3 * PI * (r1 * r1 * r1 + r2 * r2 * r2);
    l = pow(V, 1.0/3) ;// 使用立方根计算边长，注意这里不能写成1/3
    cout << int(l + 0.5)  << endl; // 强制转换，加0.5四舍五入
    return 0;
}
```
:warning:由于小数无法被精确表示，若是直接类型转换小数部分会被直接丢弃。所以在处理浮点数转整数是，应养成四舍五入的习惯，而不是直接强制转换。

可以使用round()。

从第**32**个开始，每个编号都对应一个可见符号

## 头文件 cstdio

```c 
int main() {
    char a, b, c, d;
    scanf("%c%c%c.%c", &a, &b, &c, &d);
    printf("%c.%c%c%c", d, c, b, a);
    return 0;
}
```

**常见输入输出占位符**

| 占位符 | 说明 |
| :--- | :--- |
| `%d` | 一个十进制整数，一般用于 int 类型（最常用） |
| `%nd(n 是正整数)` | 输出一个整数，如果不足 n 位，前面用**空格**补齐直到够 n 位 |
| `%I64d(Windows)`,<br>`%lld(Linux)` | 一个十进制整数，一般用于 long long 类型。要非常注意在不同的系统下，这个占位符是不一样的 |
| `%f` | 读入一个 float 类型的带小数点的浮点数，或者输出 float 或者 double 类型的浮点数，默认 6 位小数 |
| `%lf` | 读入 double 类型的浮点数 |
| `%.nf(n 是正整数)` | 用于输出一个固定 n 位小数的浮点数 |
| `%0nd(n 是正整数)` | 输出一个整数，如果不足 n 位，前面用 **0 补齐**直到够 n 位 |
| `%c` | 一个 char 类型的字符 |
| `%s` | 一个字符串 |
